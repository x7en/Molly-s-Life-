# Memories Folder

Place your photos for Molly's memories here. Name them `memory-1.jpg` through `memory-10.jpg` to match the 10 unlockable slots in the game. JPEG and PNG files both work.

Tips:
- Use square-ish images (around 512x512) for best fit in the grid.
- You can replace a memory later by swapping the file with the same name.
- If a file is missing, the slot will show a placeholder and fall back to the built-in default images (first four slots) when available.
